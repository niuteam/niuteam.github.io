# BEAM Team — website starter

**Biomedical Engineering, Acoustics & Multimodality**

A minimal, responsive one-page English website, requiring no frameworks, build tools, or third-party services.

## Publish with GitHub Pages

1. Create a free GitHub Organization (suggested account name: `beam-team-buaa`, subject to availability).
2. In the Organization, create a **public** repository named **exactly** `beam-team-buaa.github.io` (replace the prefix if you choose a different organization username).
3. Upload `index.html` and `favicon.svg` **to the repository root**, on the `main` branch. `README.md` is optional.
4. Open **Repository Settings → Pages → Build and deployment**.
5. Set **Source = Deploy from a branch**, **Branch = main**, **Folder = /(root)**. Save.
6. Once the deployment finishes, open `https://beam-team-buaa.github.io` (replace with your own organization username).

## Customize before publishing

- If your Organization username differs, update the GitHub URL in `index.html` and the instructions above.
- Update the About text and academic affiliation to accurately reflect the group's real status.
- Add a real organization contact email or activity details when available.
- The current site describes **academic interests and possible student activities**, not verified institutional recognition, past events, funded projects, or specific group members.

## Files

- `index.html` — complete website with embedded responsive CSS and SVG illustrations.
- `favicon.svg` — simple acoustic waveform icon.
- `README.md` — deployment and customization instructions.
