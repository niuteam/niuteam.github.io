NIU TEAM - SINGLE-FILE GITHUB PAGES WEBSITE
=============================================

Files:
- NIU-Team-Website.html   A complete standalone English website. All CSS, SVG graphics, and content are built into this file.

HOW TO VIEW LOCALLY
1. Download NIU-Team-Website.html.
2. Double-click it to open in Chrome, Edge, or another modern browser.

HOW TO PUBLISH WITH GITHUB PAGES
1. Create a GitHub Organization with your chosen username, e.g., niu-team-buaa (only if available).
2. Create a PUBLIC repository named exactly <organization-username>.github.io.
3. RENAME NIU-Team-Website.html to index.html.
4. Upload index.html to the repository root (not in a subfolder).
5. Go to repository Settings -> Pages, select Deploy from a branch -> main -> /(root), then Save.
6. Your eventual website address will be https://<organization-username>.github.io/.

IMPORTANT BEFORE PUBLISHING
- The 'Explore GitHub' button intentionally links to https://github.com/ because your Organization's actual URL has not been confirmed. Replace the href with the real Organization URL after creation.
- The website text is a general description of research interests, not a claim of formal university recognition or Notion Student Organization eligibility.
- GitHub Organization usernames and availability have not been verified.
- If you change the team name later, you can edit the HTML and redeploy it.

No external fonts, frameworks, images, scripts, or internet connection are needed to view the local HTML file.
